# GCLI_yuan_AI_agents

這是一個基於 Gemini CLI 與 MCP (Model Context Protocol) 構建的學術研究與個人管理 AI 團隊系統。

## 🚀 快速概覽
本專案透過「四域架構」將 AI 代理人的職能專業化，並整合多種生產力工具。

### 📂 目錄架構
- **000_Orchestrator**: 總調度、進度彙整、自動備份。
- **100_Research**: 文獻綜述、數據解讀、計畫書與論文撰寫。
- **200_Secretary**: 行政庶務、Email 處理、行程管理。
- **300_Life**: 生活管理、財務與健康追蹤。
- **_inbox**: 所有外部輸入的緩衝區。

### 🛠️ 整合工具
- **NotebookLM**: 核心知識庫。
- **Obsidian**: 筆記管理。
- **Firebase**: 資料庫查詢與數據持久化。
- **GitHub**: 版本控制與進度存檔。

## 🛠️ 核心指令 (Skill Map)
- `/inbox`: 整理收件匣並分類任務。
- `/gap`: 執行學術研究缺口分析。
- `/analyze`: 實驗數據深度解讀。
- `/sync`: 一鍵同步所有變更至 GitHub。

## 📝 開發準則
所有行為遵循 `GEMINI.md` 中定義的行動憲法，確保學術嚴謹性與資料完整性。
