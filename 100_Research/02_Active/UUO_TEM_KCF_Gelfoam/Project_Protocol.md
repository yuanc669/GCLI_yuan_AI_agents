# UUO TEM KCF Gelfoam 腎臟病理分析專案計畫書

## 1. 專案背景
本專案旨在透過透射電鏡 (TEM) 觀察 UUO (單側輸尿管結紮) 誘導的腎纖維化模型中，使用 Gelfoam 載體遞送 KCF 胜肽的治療效果。

## 2. 實驗組別定義
根據使用者提供之資訊，完整組別架構如下（目前 Inbox 僅包含標註 * 之組別）：
- **Sham-L**: 對照組 (Left side) *
- **UUO-L**: 模型組 (Left side) *
- **UG**: UUO + Gelfoam (無胜肽)
- **U0.75G**: UUO + Gelfoam + KCF (0.75 mg/kg)
- **U1.5G**: UUO + Gelfoam + KCF (1.5 mg/kg)
- **U3G-L**: UUO + Gelfoam + KCF (3.0 mg/kg, 最高劑量組) *

> 註：L 指手術側 (Left)，R 指對稱側 (Right)。

## 3. 分析指標 (Key Indicators)
針對 TEM 影像，將重點量化與觀察以下指標：
1. **腎小球基底膜 (GBM) 厚度**: 評估基底膜增厚程度。
2. **足細胞足突融合 (Podocyte effacement)**: 評估足細胞損傷與濾過屏障完整性。
3. **線粒體損傷**: 觀察線粒體嵴斷裂、腫脹、空泡化等超微結構改變。
4. **膠原沉積量化**: 評估間質纖維化程度。
