# Kale NV (羽衣甘藍) 進階蛋白質組學分析報告 (Advanced Analysis Report)

**分析目標**: 鑑定植物外泌體 (EV) 保守標誌物、十字花科特有的防禦/代謝系統 (Glucosinolate-Myrosinase)、以及潛在的跨物種調控分子。

## 1. 植物外泌體保守標誌物鑑定 (EV Marker Benchmarking)
在 Kale NV 中鑑定出多個高度保守的植物 EV 標誌物，證實了該樣本具備典型的外泌體結構特徵。

| 蛋白質名稱 (Protein Description) | Accession | 生物學意義 |
| :--- | :--- | :--- |
| **Annexin** | A0A0D3CGB8 | 鈣離子依賴型膜結合蛋白，植物 EV 最核心標誌物。 |
| **Ras-related protein Rab7** | A0A0D3DJP5 | 囊泡運輸與多囊泡體 (MVB) 形成的關鍵調節因子。 |
| **Plasma membrane ATPase** | A0A0D3D2T1 | 維持膜電位與跨膜運輸，植物 EV 常見組分。 |
| **V-type proton ATPase** | A0A0D3D1P5 | 參與囊泡酸化與貨物裝載。 |
| **UDP-arabinopyranose mutase** | A0A0D3B1C1 | 參與細胞壁合成，常隨 EV 分泌至胞外。 |

**結論**: Kale NV 包含豐富的 **Annexin** (Rank 10) 與 **Rab7**，證明提取物具有極高的植物外泌體純度。

## 2. 十字花科核心防禦系統：硫代葡萄糖苷-黑芥子酶 (Glucosinolate-Myrosinase)
這是 Kale NV 最具特色的功能模組，與其抗癌與免疫調節活性直接相關。

| 蛋白質名稱 (Protein Description) | Accession | 全域排名 (Rank) | 功能解析 |
| :--- | :--- | :--- | :--- |
| **thioglucosidase (Myrosinase)** | A0A0D3AXF1 | **6** | 催化硫代葡萄糖苷水解產生異硫氰酸酯 (如萊菔硫烷)。 |
| **Myrosinase-associated protein** | A0A0D3CQU2 | - | 穩定黑芥子酶複合體，增強其在逆境下的活性。 |
| **nitrilase (腈水解酶)** | A0A0D3AJG2 | **14** | 參與吲哚-3-乙酸 (IAA) 合成，或將腈類轉化為酸類。 |

**重要發現**: **Myrosinase** 位列全數據豐度第 6 名，這顯示 Kale NV 是傳遞該酵素的絕佳載體。這支持了「Kale NV 通過在腸道內傳遞 Myrosinase，促進膳食中前體物質轉化為活性異硫氰酸酯」的生物學假設。

## 4. 蛋白質與 RNA 運載機制對比 (Comparative Insight)
與 Ginger NV 相比，Kale NV 的特徵如下：
*   **共同點**: 均含有高豐度的 **Annexin** 與 **Rab** 家族蛋白。
*   **相異點**: 
    *   Ginger NV 含有顯著的 **AGO1** (RNAi 核心)，暗示其強大的 RNA 運載能力。
    *   Kale NV 的 RNA 處理蛋白相對較少 (僅鑑定到 **RNA helicase**)，但其特異性地富集了 **Myrosinase** 系統，暗示其功能偏向於「小分子代謝物」的合成調節。
