# Data Insight: Baseline & Control Analysis (Sham vs HS Groups)

## 📌 數據來源
1. `L7_Sham_HS2W-1.xlsx` (早期對比)
2. `L7_Sham_Sham10W_1.xlsx` (老化/長期對照)
3. `L7_Sham10W VS HS10W-1.xlsx` (晚期病變對比)
4. `L7_Sham10W_SS10W_HFD10W_HS10W-1.xlsx` (多因子打擊對比)

## 🧪 核心發現 (Key Findings)
1. **基準穩定性**: 在所有 Sham 組（不論週數）中，`Bacteroides_H_857956` (11.4%) 與 `unclassified Bacteroidota` 為最穩定的優勢菌群。
2. **早期偏移 (Sham vs HS2W)**: `Kineothrix` 在早期 (W2) 即展現出佔比波動 (約 6.8%)，暗示代謝紊亂初期對厚壁菌門的敏感影響。
3. **晚期病變特徵 (HS10W)**: 在 HS10W 組中，`Bacteroides_H_857956` 依然維持高佔比，但整體群落多樣性預期將隨病程延長而下降。
4. **多因子交互**: 數據顯示 HFD 與 STZ 的組合 (HS) 相比單一因子 (SS 或 HFD)，對菌叢結構的改變具有加乘效應。

## 💡 分析建議
- **對照組歸一化**: 在進行 GaExo 療效評估前，應先利用這些 Sham 組數據建立「健康菌叢基準線」。
