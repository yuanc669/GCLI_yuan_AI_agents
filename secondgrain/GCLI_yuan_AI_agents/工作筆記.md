## 🕳️ 踩坑筆記

- **MarkItDown Dependencies**: 預設 pip 安裝不含 PDF/PPTX 支援，須執行 `pip install "markitdown[all]"`。
- **Encoding Conflict**: Windows 環境重導向輸出會報 cp950 編碼錯誤，須改用內建 `-o` 參數直接寫入檔案。
- **Git Remote**: 最初推送時遠端尚未建立，已透過 GitHub CLI (`gh`) 補齊。
- **&& 語法**: PowerShell 環境下不支援 `&&`，需改用 `;`。
- **Hook 路徑**: Windows 環境下 SessionEnd Hook 需使用絕對路徑並呼叫 bash。
- **MCP Upgrade**: 在 CLI 執行中升級 NotebookLM MCP 會因檔案正由另一個程序使用而出現 `os error 32`，須關閉 CLI 後再手動執行。
