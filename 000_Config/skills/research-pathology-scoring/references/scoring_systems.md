# Pathology Scoring Systems Reference

## Overview
This reference provides detailed scoring criteria for various animal models of disease, including liver, lung, kidney, and intestine injury.

## Scoring Systems by Organ/Disease

| Disease / Model | Organ | Scoring System | Description & Grading Criteria | Reference |
| :--- | :--- | :--- | :--- | :--- |
| **Sepsis / I/R** | Liver | **Suzuki Score** | 0: Normal.<br>1: Minimal congestion/vacuolization.<br>2: Mild congestion/vacuolization, necrosis <10%.<br>3: Moderate congestion/vacuolization, necrosis 10–60% (Focal).<br>4: Severe congestion/vacuolization, necrosis >60% (Confluent). | Suzuki, S., et al. (1993) |
| **Sepsis / Pneumonia** | Lung | **ATS ALI Score** | A. Neutrophils in alveolar space: 0 (none) to 2 (>7).<br>B. Neutrophils in interstitium: 0 (none) to 2 (>15).<br>C. Hyaline membranes: 0 (none) to 2 (>2).<br>D. Proteinaceous debris: 0 (none) to 2 (>2).<br>E. Alveolar wall thickening: 0 (normal) to 2 (>2x thickness). | Matute-Bello, G., et al. (2011) |
| **Obesity / Metabolic** | Liver | **NAS Score** | 1. Steatosis: 0(<5%), 1(5-33%), 2(34-66%), 3(>66%).<br>2. Lobular Inflammation: 0(none), 1(<2 foci), 2(2-4 foci), 3(>4 foci/200x).<br>3. Ballooning: 0(none), 1(few), 2(many/prominent). | Kleiner, D. E., et al. (2005) |

## Key Pathological Features
1. **Liver Ballooning (NAS Score)**: Key for NASH; characterized by cell swelling, wispy cytoplasm, and Mallory-Denk bodies.
2. **Renal Tubular Injury (Paller Score)**: Monitor brush border integrity; PAS staining is superior to H&E for this.
3. **Acute Lung Injury (ALI Score)**: Focus on Hyaline Membrane formation, representing severe blood-air barrier damage.

## Practical Suggestions
- **Staining Choice**: 
    - Liver/Kidney (Metabolic/Diabetes): Add PAS (basement membrane) and Masson's Trichrome (fibrosis).
    - Lung/Intestine: H&E is primary; MPO staining for neutrophil quantification.
- **Double-Blind Principle**: Scoring should be done by two researchers independently. If the difference is >1 point, a third researcher must achieve consensus.
