# AI 團隊完整工作架構與 Skill 地圖

## 一、四域架構 (Domain Framework)
- **000_Orchestrator/**: 總調度（跨域協調、記憶整合、週報生成）
- **100_Research/**: 研究團隊（論文研讀、數據解讀、計畫書撰寫）
- **200_Secretary/**: 秘書團隊（Email 處理、行程管理、聯絡對接）
- **300_Life/**: 生活團隊（家庭事務、財務規劃、健康追蹤）
- **_inbox/**: 統一收件區（所有外部輸入的緩衝入口）

## 二、MCP 工具整合表 (Tool Integration)
| 工具 | 功能 | 應用場景 |
| :--- | :--- | :--- |
| **Gmail** | 搜尋/讀信、起草 Email | 秘書域：處理外部聯繫 |
| **Google Calendar** | 查詢/建立/更新行程 | 秘書域：排定會議與截止日 |
| **Google Drive** | 搜尋/讀取雲端檔案 | 跨域：資料存取與分析 |
| **Obsidian** | 讀寫筆記、管理 Frontmatter | 總調度：視覺化知識大腦 |
| **Supabase** | 資料庫查詢與管理 | 總調度：長效數據持久化 |
| **NotebookLM** | 建立知識庫、生成 Podcast | 研究域：深度文獻綜述 |

## 三、Skill 指令清單 (Skill Map)

### 🗂️ 總調度域 (000_Orchestrator)
| 指令 | 觸發方式 | 功能描述 |
| :--- | :--- | :--- |
| `/inbox` | 「幫我整理 inbox」 | 全區掃描，分派處理至各域 |
| `/sync` | 「同步到 github」 | 執行 `tools/shutdown.py` 邏輯 |
| `/status` | 「目前進度如何」 | 彙整 `_inbox/tasks.md` 的狀態報告 |

### 🔬 研究域 (100_Research)
| 指令 | 觸發方式 | 功能描述 |
| :--- | :--- | :--- |
| `/gap` | 「分析研究缺口」 | 執行機制/轉譯/方法學三軸分析 |
| `/analyze` | 「解讀這份數據」 | 執行結果->脈絡->推論三階解讀 |
| `/abstract` | 「寫摘要」 | 生成符合學術規範的四段式摘要 |

### 📧 秘書域 (200_Secretary)
| 指令 | 觸發方式 | 功能描述 |
| :--- | :--- | :--- |
| `/email-action` | 「處理這封信」 | 提取行動項並寫入 `tasks.md` |
| `/email-reply` | 「幫我回信」 | 根據背景起草專業回覆草稿 |
| `/schedule` | 「排進日曆」 | 自動檢查衝突並更新 Google Calendar |

---
**核心準則**：所有行動遵循「提議權」機制，大型變動需經使用者確認。
