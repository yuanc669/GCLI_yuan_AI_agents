# Skill: Travel Planning (/travel-plan)

## 📋 概述
協助使用者進行旅遊規劃，包含行程安排、預算估算、行李清單及交通/住宿對齊。

## 🛠️ 觸發條件
- 使用者輸入「規劃旅遊」、「我想去 [目的地]」或直接調用 `/travel-plan`。

## 📝 執行流程
1. **需求對齊**：
   - 目的地與日期。
   - 預算範圍（經濟/平衡/奢華）。
   - 參與成員（個人/家庭/朋友）。
   - 旅遊偏好（自然/城市/美食/歷史）。
2. **行程設計**：
   - 產出日為單位的行程表（Day 1, Day 2...）。
   - 包含景點、建議停留時間、交通接駁建議。
3. **財務估算**：
   - 估計機票、住宿、餐飲、門票費用。
4. **清單準備**：
   - 依據目的地天氣產出必帶清單（證件、衣物、藥品）。

## 📂 輸出規範
- **格式**：Markdown。
- **存檔路徑**：`300_Life/records/[YYYYMMDD]_[Destination]_Plan.md`。
- **樣式**：
  - 使用表格呈現行程。
  - 使用勾選清單 (Checkbox) 呈現行李清單。

## ⚠️ 限制
- 僅提供規劃建議，不具備實際下單訂購權限。
- 數據依據現有網路資料與使用者提供之 context。
